ObjeX

Self-hosted S3-compatible object storage in Go — with optional multi-node quorum replication.

Built by Vishal Painjane

View on GitHub Case study
Go AWS SigV4 Multipart Quorum N/R/W Hinted handoff Docker Prometheus

Quick start

git clone https://github.com/VishalPainjane/ObjeX.git
cd ObjeX
docker compose up -d --build
# S3 endpoint: http://localhost:9000

Cluster demo

docker compose -f docker-compose.cluster.yml up -d --build
curl http://localhost:9001/cluster

What to highlight in interviews

  • S3 API compatibility + SigV4 auth
  • Content-addressable storage and atomic writes
  • Distributed placement, quorum, hints, read repair
  • Integration tests with multi-node fault injection
