ObjeX gives your applications a local S3 endpoint for development and CI, or a three-node cluster with quorum replication — one static binary, no cloud account required.

Product

One platform for local dev, CI, and small-scale distribution

Metadata in SQLite. Blobs on disk. Cluster mode adds replication without changing your SDK code.

S3 API your SDK already speaks

Point aws-cli, boto3, or the AWS SDK at ObjeX. Same PUT, GET, HEAD, DELETE, listing, Range, multipart, and batch delete.

  • AWS Signature Version 4 on all object routes
  • Presigned GET/PUT for shareable upload links
  • Content-addressed blobs with atomic writes

Cluster mode when one machine is not enough

Static membership, rendezvous placement, primary forwarding. The primary coordinates quorum writes and fans out replicas.

  • Configurable replication factor and read/write quorum
  • Durable hints when a replica is temporarily offline
  • Peer health probes and background healing

Quick start

Running in under a minute

git clone https://github.com/VishalPainjane/ObjeX.git
cd ObjeX
docker compose up -d --build
# http://localhost:9000
export AWS_ACCESS_KEY_ID=OBXTESTKEY00000001
export AWS_SECRET_ACCESS_KEY=testsecretkeythatislongenoughforhmacsha256test
aws --endpoint-url http://localhost:9000 s3 mb s3://photos
aws --endpoint-url http://localhost:9000 s3 cp file.txt s3://photos/
docker compose -f docker-compose.cluster.yml up -d --build
curl http://localhost:9001/cluster
